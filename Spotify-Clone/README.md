# 🎵 Spotify Clone

A web-based music player clone inspired by Spotify's design. This project is part of my journey to becoming a **Full Stack Developer (MERN)**.

## 🚀 About The Project
Currently, the UI is fully designed and responsive. I am now working on the **JavaScript Logic** to make the player functional (Play, Pause, Seek, Next/Prev).

### 🛠️ Tech Stack
- **HTML5** (Structure)
- **CSS3** (Flexbox, Grid, Responsive Design)
- **JavaScript** (DOM Manipulation & Logic - *In Progress*)

### ✨ Features (Current Status)
- ✅ **Professional UI:** Sidebar, Song Cards, and Bottom Player Bar.
- ✅ **Hover Effects:** Spotify-style Green Play Button on cards.
- ✅ **Responsive Grid:** Layout adapts to screen size.
- ⏳ **Audio Logic:** Play/Pause functionality (*Coming this week*).
- ⏳ **Seekbar:** Dynamic progress bar (*Coming this week*).
